# Tasty Tales — Food Blog & Recipe Website

A frontend-only student project built with HTML5, CSS3, and vanilla JavaScript.

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Create a demo account on Sign up, then log in.
4. Browse recipes and save favourites.

## Features
- Responsive homepage, recipe listing, recipe details, blogs, favourites, sign-up and login pages.
- Recipe search and category filtering.
- JavaScript form validation.
- Demo account and favourite recipes saved with browser Local Storage.
- No database or backend required.

## Important
This is a classroom frontend demonstration, not secure authentication. Demo account data is stored in the browser's Local Storage. Do not use a real password. Data stays in that browser and does not sync between devices.

## Publish on GitHub Pages
Create a public GitHub repository, upload the contents of this folder, then go to **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save. Ensure `index.html` is at the repository root.
